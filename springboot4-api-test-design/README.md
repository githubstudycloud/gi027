## 核心信条

- **OpenAPI / AsyncAPI = 单一事实源**：文档、Mock、SDK、用例骨架、连通探针由它派生。
- **PRD-as-Code**：需求入仓、AC 编号永不复用、双向追溯到用例与日志。
- **接口 = 内部 + 外部**：统一在 `catalog.yaml` 注册，连通三层语义（网络 / 协议 / 业务）。
- **数据可预填可重置**：Fixture + Builder + 固定 seed，失败可一键复现。
- **左移发现**：契约偏离探测、慢调用预警、错误模式聚合、连续冒烟"四只眼"在用户告知前发现问题。
